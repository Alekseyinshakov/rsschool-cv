Инструменты и технологии

React-приложения

  • Green-shop
    Деплой | Репозиторий
    Green-shop — интернет-магазин растений, разработанный в команде из трёх человек в рамках курса по фронтенд-разработке от Rolling Scopes School. Проект построен с использованием React и TypeScript, управление состоянием реализовано через Zustand. В качестве бэкенда используется API Commercetools .

  • Note manager
    Деплой | Репозиторий
    Менеджер заметок — приложение для создания и управления заметками, разработанное с использованием React. Пользователи могут добавлять, редактировать и удалять заметки. Для хранения данных используется локальное хранилище браузера.

Vanilla JS-приложения

  • Image-gallery(API)
    Деплой | Репозиторий
    Image-gallery — приложение для просмотра изображений, использующее API Unsplash. Пользователи могут искать изображения по ключевым словам и просматривать их в полноэкранном режиме. Приложение реализовано на чистом JavaScript.

  • Simon says
    Деплой | Репозиторий
    Simon says — игра на запоминание последовательности чисел и букв. Игрок должен повторить последовательность, которая генерируется компьютером. Реализовано на чистом JavaScript.

  • Nonograms
    Деплой | Репозиторий
    Nonograms — логическая игра, в которой игрок должен заполнить клетки на сетке по заданным подсказкам. Реализовано на чистом JavaScript. Игрок может выбирать размер сетки и уровень сложности. Игра включает в себя возможность сохранения и загрузки игр, а также выбор случайных головоломок. Чтобы закрасить клетку, используется ЛКМ, а для крестика — ПКМ. Повторный клик удаляет отметку.

  • Async-race
    Деплой | Репозиторий | API
    Async race — одностраничное приложение (SPA) на JavaScript для управления коллекцией радиоуправляемых автомобилей и проведения онлайн-гонок. Вся логика взаимодействия с машинами (запуск/остановка двигателя, движение) реализована через HTTP-запросы к серверу. Приложение включает CRUD-операции, анимацию гонок и таблицу победителей. Для работы потребуется запустить серавер с API.

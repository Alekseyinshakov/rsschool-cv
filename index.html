React-приложения

  • Green-shop
    Деплой | Репозиторий
    Green-shop — интернет-магазин растений, разработанный в команде из трёх человек в рамках курса по фронтенд-разработке от Rolling Scopes School. Проект построен с использованием React и TypeScript, управление состоянием реализовано через Zustand. В качестве бэкенда используется API Commercetools .

  • Note manager
    Деплой | Репозиторий
    Менеджер заметок — приложение для создания и управления заметками, разработанное с использованием React. Пользователи могут добавлять, редактировать и удалять заметки. Для хранения данных используется локальное хранилище браузера.
